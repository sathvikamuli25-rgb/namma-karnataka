# Namma Karnataka 🌿

### Discover. Explore. Experience.

Namma Karnataka is a tourism website designed to help people discover the beauty, culture, heritage, and popular destinations of Karnataka, India.

## 📌 Problem Statement

Travelers may find it difficult to discover destinations, plan trips, and access useful information about places to visit in Karnataka.

Namma Karnataka aims to make exploring Karnataka easier through an interactive website and an AI-powered travel planner.

## ✨ Features

- 🏞️ **Explore Destinations:** Discover popular tourist destinations across Karnataka.
- 🗺️ **District Exploration:** Explore destinations across different districts.
- 🤖 **AI Travel Planner:** Get assistance with planning a trip to Karnataka.
- 📱 **Responsive Design:** Access the website on desktops, tablets, and mobile devices.
- 🎨 **Interactive Interface:** Navigate the website through a user-friendly interface.
- 🌿 **Discover Karnataka:** Learn about the state's tourism, culture, and heritage.
